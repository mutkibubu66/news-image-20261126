This is my entry for the make.fun bounty
[news-image-20261126](https://make.fun/c/news-image-20261126):
one newspaper front page that sums up the world news of
Thursday 26 November 2026.

`main.ts` copies the finished front page, `entry.png`, into the
output directory named by `MAKEFUN_OUTPUT_DIR` (or `out` when that
variable is not set). Run it with:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

## The six stories on the front page

- **Pakistani astronaut joins China's space station** — Pakistan's first astronaut will fly aboard China's Shenzhou-24 mission to the Tiangong station.
- **US proposes new tariffs on 14 partners** — Washington proposed new tariffs on fourteen trading partners over industrial overcapacity.
- **Cairo tanker fire kills 31** — A fuel tanker crashed and caught fire on a Cairo highway, killing thirty-one people.
- **North Korea expels Swiss diplomat** — Pyongyang ordered the head of Switzerland's diplomatic office to leave over sanctions.
- **US stocks slide on AI fears** — American shares fell sharply as worries over artificial intelligence deepened.
- **Record migrant arrival in Canary Islands** — Nearly two thousand migrants reached Spain's Canary Islands in a single day, a record.
